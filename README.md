# 미션 - 다리 건너기

## 기능 구현 목록
1. 시작 메시지 출력
2. 다리 길이 입력 및 검증
   - 예외 사항
     - 숫자가 아닌 경우 -> Validator
        - 다리 길이는 3부터 20 사이의 숫자여야 합니다.
     - 3~20 정수가 아닌 경우 -> 도메인
        - 다리 길이는 3부터 20 사이의 숫자여야 합니다.
3. 다리 생성
4. 이동할 칸 선택 및 검증
   - 예외 사항
     - U 또는 D가 아닌 경우 -> 도메인
       - U 또는 D를 입력하세요.
5. 이동할 칸에 다리가 있는지 확인
   1. 있으면 O를 출력 후 계속 진행
   2. 없으면 X를 출력 후 게임 진행 여부 입력 및 검증
      - 예외 사항
        - R 또는 Q가 아닌 경우
          - R 또는 Q를 입력하세요.
      1. R인 경우
         - 생성된 다리와 시도 횟수 기록만 남기고 초기화 후 이동할 칸 선택으로 이동
      2. Q인 경우
         - 최종 게임 결과 출력 후 종료
